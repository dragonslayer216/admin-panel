# Admin Panel

A modern admin dashboard with a dark glass-inspired UI, user management, analytics cards, and settings panel.

## Features

- Dashboard overview with KPI cards
- User management table with add, edit, and delete actions
- Search filtering
- Orders and support sections
- Responsive layout
- Simple modal-based CRUD interactions

## Run locally

1. Open `index.html` directly in your browser, or
2. Serve the project with a lightweight local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — page structure
- `styles.css` — design system and responsive layout
- `script.js` — dashboard behavior and user actions

## Notes

This is a frontend-only admin panel demo. It stores data in the browser and is ready to be connected to a backend later.
