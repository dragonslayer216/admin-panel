Admin Panel Keyboard Shortcuts & Button Guide

🎮 Keyboard Shortcuts

Key Action Description
Alt + D Go to Dashboard Navigate to the main dashboard view
Alt + U Go to Users Navigate to user management page
Alt + S Go to Settings Navigate to settings page
Alt + H Go to Help Show this help page with shortcuts
Escape Close Modal Close any open dialog or modal window
Ctrl + S Save Form Save changes in any form (when modal is open)
Ctrl + N New User Open Add New User modal (from Users page)
Delete Delete Selected Delete the last highlighted user

🔘 Button Guide

Primary Button (Blue)

Used for main actions like adding new items, saving forms, or confirming important actions.

Edit Button (Green)

Click to modify user information or settings. Opens an edit form or modal dialog.

Danger Button (Red)

Used for destructive actions like deleting users. Requires confirmation before executing.

Active

Status Badge (Green)

Indicates that a user or resource is currently active and operational.

Inactive

Status Badge (Red)

Indicates that a user or resource is inactive or disabled.

📋 Navigation Guide

  • Dashboard: View overview statistics and recent user activity
  • Users: Manage all users - add, edit, or delete user accounts
  • Settings: Configure admin panel settings like site name and timezone
  • Help/Keys: This page - view all shortcuts and button descriptions
  • Logout: Sign out of the admin panel

💡 Tips & Tricks

  • Use keyboard shortcuts for faster navigation
  • Hover over cards on the dashboard to see additional information
  • All destructive actions require confirmation to prevent accidents
  • Use the search functionality to filter users (coming soon)
  • Export user data for backups (coming soon)
